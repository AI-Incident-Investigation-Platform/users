# users и требования продукта

Сверка с документацией продукта
([AI-Incident-Investigation-Platform/docs](https://github.com/AI-Incident-Investigation-Platform/docs)),
редакция baseline v3 с машинными контрактами в `contracts/`.

Статусы: **есть** — реализовано; **частично**; **нет** — не начато;
**расходится** — сделано иначе, причина рядом.

## Профиль и поиск — `contracts/AUTH_BOUNDARY.md`, 02 UC-02, 04 §маршруты

| Требование | Статус | Комментарий |
|---|---|---|
| Профиль создаётся после регистрации, юзернейм из почты, если человек его не задал | есть | по событию `user.registered` |
| Форма профиля после регистрации: юзернейм, имя, часовой пояс, рабочее время; `onboarded_at` | есть | `PATCH /api/v1/users/me` |
| Юзернейм уникален, проверка занятости по мере ввода | есть | фильтр Блума + индекс БД |
| Поиск людей по юзернейму, почте и имени для приглашений | есть | `GET /api/v1/users?q=` |
| Профили пачкой для списков участников | есть | `GET /api/v1/users/lookup` |
| Почта в профиле следует за сменой почты в `auth` | есть | событие `user.email_changed` |
| Аватар | есть | SeaweedFS, без аватара фронтенд рисует инициалы |
| `GET /me` отвечает профилем сразу после регистрации | есть | профиль по `auth/me`, если события ещё нет |
